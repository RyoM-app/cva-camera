# CVAカメラ 0.2.0

体の横に置いたスマホの**内カメラ**で、耳珠・C7・肩峰の色マーカーをブラウザ上で追跡し、CVAと渡邉角をリアルタイムに計算して記録します。
映像は保存・送信しません。保存されるのは、時刻・マーカーの座標・角度だけです。

角度の定義と計算は `cva-marker-tracker/cva_tracker.py`（Python版）と同じです。

## 使い方（1人で実験できます）

1. HTTPSで公開したページを、側面カメラ用のスマホのSafari/Chromeで開く
2. スマホを体の真横に、**画面を自分に向けて**立てる（高さは肩、1〜2 m）
3. 「内カメラを開始」→ カメラの使用を許可する
4. セルフタイマーを選んで「写真を撮る」。合図の音が鳴るまで、正面を向いて楽な姿勢でいる
5. 撮った**写真の上で**、耳珠 → C7 →（肩峰）の順にマーカーをタップする。写真でのCVAが表示される
   - 壁の水平なテープが写っていれば「水平線」で2点タップして、カメラの傾きを補正できる
   - うまく指定できなければ「撮り直す」
6. 待ち時間と進め方を選んで「記録スタート」。カウントダウンのあと、ライブ映像で追跡と記録が始まる
   - **自動**：うなずき → 基準 → うつむく → 顎を突き出す → 目線だけ下げる → 基準 → うなずき を音声で案内し、自動で終わる（1姿勢の時間は設定可能）
   - **手動**：姿勢を変えるたびにラベルを押し、最後に「記録停止」
7. 「CSVを保存」「全記録JSONを保存」

画面は左右反転していません（記録される座標と同じ向き）。

## 記録の中身

| 列 | 内容 |
|---|---|
| `epoch_ms` | Unix時刻[ms]。`performance.timeOrigin + perf_ms`。posture-labの `meta.timeOrigin + t` と同じ基準 |
| `capture_perf_ms` | 撮影時刻（ブラウザが対応している場合のみ） |
| `label` | そのときの姿勢のラベル |
| `tragus_x` … `acromion_area` | 各マーカーの重心（映像の画素、左上が原点）と面積 |
| `cva_deg`, `watanabe_deg` | CVA、渡邉角（度） |
| `valid` | CVAが求まったか（1/0） |
| `device_tilt_deg` | 側面カメラのスマホの傾きの目安（0°に近いほど水平。記録のみで補正には使わない） |

JSONには、色の設定・映像の解像度・傾き補正・ラベルと同期の合図のイベント列も入ります。

### 2台のスマホの時刻合わせ

両方の端末の時計（Unix時刻）で大まかに合います。ただし端末の時計どうしは数十〜数百ms ずれることがあるため、最終的には**うなずきの山**（posture-labの頭部角度と、CVAカメラのCVAが同時に大きく変わる瞬間）で合わせます。

## 動作確認（2026-10-23、パソコンのブラウザの疑似カメラ）

| 試験 | 結果 |
|---|---|
| 疑似カメラ：既知のCVA 55°→40°の映像 | 275/275フレームで検出。最大誤差 0.22° |
| 疑似カメラ：実際のマーカー写真（test_photo1） | CVA 42.74°（Python版 42.64°）、渡邉角 3.39°（Python版 3.38°） |
| 0.2.0：写真でタップ → 手動で記録（55°→40°の映像） | 272/272フレームで検出。最大誤差 0.20° |
| 0.2.0：自動の音声案内（1姿勢3秒） | 21秒で自動終了。ラベルと同期の合図が順に記録された |

実機（iPhone・Android）での動作、処理速度、発熱は**まだ確認していません**。

## 調整

「検出の調整」で、色相の許容幅、最小の大きさ、処理の解像度を変えられます。「色の検出範囲を表示」で、色として拾っている範囲を紫で確認できます。肌や服を拾っている場合は、色相の許容幅を狭めてください。
